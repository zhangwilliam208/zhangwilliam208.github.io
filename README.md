# 方块营地

面向《我的世界》玩家的静态单页站点初稿，包含房间接入、社区论坛、游戏内服务和技术支持入口。页面采用原创 CSS 像素插画，没有外部图片、字体或 JavaScript 依赖。

## 本地预览

直接在浏览器打开 `index.html` 即可查看布局。支持表单只在浏览器中整理求助内容；配置 `index.html` 顶部的 `SUPPORT_EMAIL` 后，会打开预填邮件，不会把表单数据发送到服务器。

## 正式上线前需要补充

- 最终站点名称，以及由谁负责运营/销售。
- 服务器平台、版本、接入地址、规则和是否收费。
- 论坛链接和真实的技术支持联系渠道。
- 装备/游戏币的品类、定价、购买记录查询、退款与支持方式。
- 隐私说明、社区规则，以及适用于目标地区的交易/消费者信息。
- 将源码中“方块营地”和“等待运营者补充”等初稿内容换成准确资料。

当前没有支付、登录、论坛后端或订单系统。商品区明确显示“当前未开放购买”，不会收款或创建订单。

## 《我的世界》品牌与商业使用

页面使用原创像素风格，不包含官方纹理、标志或游戏截图，并保留醒目的非官方声明。发布前请核对 Mojang 当前的[使用指南](https://www.minecraft.net/en-us/usage-guidelines)和 [EULA](https://www.minecraft.net/en-us/eula)。官方指南要求说明服务责任主体、卖家/运营者和可直接联系的渠道，并要求避免造成官方关联的印象；论坛或聊天链接本身不能作为购买/服务联系方法。服务器接入、服内货币和影响游戏平衡的商品也需要按指南分别确认后再开放。

## 托管

这是纯静态网站，可以部署到支持静态文件的托管服务。当前会话没有可用的网站发布入口：已有 GitHub 连接可操作仓库文件，但账号没有专用网站仓库，也没有在连接器中创建仓库或配置 Pages 的能力。获得可用的发布入口后，可直接使用本目录内容部署。
